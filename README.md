# Swapi Async - Асинхронная загрузка персонажей Star Wars

Асинхронный Python-скрипт для загрузки данных персонажей из API Star Wars (SWAPI) в локальную базу данных SQLite.

## Требования

- Python 3.7+
- aiohttp==3.13.5
- aiosqlite==0.22.1

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd Swapi_async
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Использование

Перед первым запуском убедитесь, что файл базы данных `swapi_characters.db` существует в корне проекта. Если файла нет, создайте его вручную или используйте предоставленный файл.

Запустите скрипт:
```bash
python async_swapi.py
```

Программа выполнит следующие действия:
1. Выполнит SQL-миграцию для создания таблицы `characters`
2. Получит общее количество персонажей из API
3. Загрузит данные всех персонажей асинхронно (пакетами по 50)
4. Сохранит данные в базу данных
5. Выведет итоговое количество сохраненных персонажей

## Структура базы данных

Таблица `characters` содержит следующие поля:
- `id` - уникальный идентификатор персонажа
- `birth_year` - год рождения
- `eye_color` - цвет глаз
- `gender` - пол
- `hair_color` - цвет волос
- `homeworld` - родной мир
- `mass` - масса
- `name` - имя
- `skin_color` - цвет кожи

## Логирование

Скрипт использует модуль `logging` с форматом:
```
%(asctime)s - %(levelname)s - %(message)s
```

Уровни логирования:
- `INFO` - прогресс загрузки и основные события
- `WARNING` - предупреждения (например, не-ok ответы от API)
- `ERROR` - ошибки (таймауты, сетевые ошибки)
- `EXCEPTION` - непредвиденные ошибки с трассировкой стека

## Архитектура

### Основные компоненты:

- **`init_db()`** - асинхронная функция инициализации БД через миграции
- **`fetch(session, char_id)`** - асинхронная функция получения данных персонажа
- **`main()`** - основная функция, координирующая процесс загрузки

### Обработка ошибок:

Скрипт обрабатывает следующие типы ошибок:
- `asyncio.TimeoutError` - таймауты запросов
- `aiohttp.ClientError` - сетевые и HTTP ошибки
- `Exception` - все остальные непредвиденные ошибки

Все ошибки логируются с подробным описанием для удобства отладки.

## Конфигурация

Константы в начале файла:
```python
DB = "swapi_characters.db"        # Имя файла базы данных
MIGRATION = "migration.sql"        # Файл миграции
URL = "https://www.swapi.tech/api/people/{id}/"  # URL API
```

Параметры сессии:
- Лимит подключений: 10
- Таймаут: 30 секунд
- Размер пакета: 50 персонажей
